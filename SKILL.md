# README Writing Skill

## Purpose
This skill is designed to help agents write clear, concise, and informative README files for projects. It ensures that the README effectively communicates the purpose, usage, and other essential details of the project to users and contributors.

## When to Use
When creating a new project, updating an existing README, or when the current README lacks clarity or completeness. This skill is particularly useful for open-source projects, internal tools, and any software that requires documentation for users and developers.

## When Not to Use
Situations where another skill/workflow is more appropriate.
